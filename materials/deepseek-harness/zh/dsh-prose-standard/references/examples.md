# 提炼的文字示例

用示例识别支配原则，不当文字模板。“平衡版”用该位置所需最少解释保留全部承重命题。

## 保留每个事实子句

**原文：**“协调器仔细地按会话串行写入，在释放完成前刷出缓冲事件，并向调用者报告后端失败。”

**过度删减：**“协调器串行持久化。”

**平衡版：**“协调器按会话串行写入，在释放完成前刷出缓冲事件，并向调用者报告后端失败。”

删修饰及重复，不删命题。行动者、逐会话范围、释放顺序及失败可见性是独立事实。

## 明确技能范围具有功能作用

**过度删减：**“读来源，运用判断。”

**平衡版：**“本技能是指导，不是完整清单。在具名检查之外运用判断；已记录要求仍适用。”

**过度详细：**数段辩护为何清单无法替代独立推理。

保留明确限制，因为它改变 agent 如何应用流程。删重复劝说，不删护栏。

## 实践指南保留动作及验证

**过度删减：**“给工具加测试。”

**平衡版：**“单元级测试注册与释放，经真实加载器路径使用工具，渲染输出变化时加快照。验证断言观察外部结果，而非模型报告。”

**过度详细：**走读示例代码已可见的每个夹具文件及断言。

保留测试层次、必需动作、真实入口及可观察验证。删夹具叙述。

## 保留责任归属及时机

**过度删减：**“拆除时取消提供者工作。”

**平衡版：**“运行时释放子作用域前请求提供者取消；提供者仍负责在释放完成前等待自己的 worker 结束。”

**过度详细：**按时间叙述实现拆除的每个 Promise 及回调。

行动者、顺序、责任转移点及完成保证是独立事实子句。

## 事件 JSDoc 保留边界时机

**过度删减：**“组合并缓存会话前缀。”

**平衡版：**“在首次 pre-step 与模型请求之前组合一次会话前缀。监听器追加进入当前请求，pre-step 压力核算收到组合前缀。”

**过度详细：**走读实现顺序的循环辅助函数、缓存字段及 Promise 回调。

事件顺序及对当前请求的影响是调用者可见行为，不是实现叙述。

## 为复杂代码定位，不叙述代码

**过度删减：**“Worker realm 支持。”

**平衡版：**“负责 worker realm 及其 Host 桥。Realm 初始化仅一次；释放会终止 worker 并拒绝后续调用。协议理由见 worker 隔离 Agent Note。”

**过度详细：**逐段预告下面的类及辅助函数。

保留模块角色、依赖、职责及非显然生命周期行为。链接架构理由，让代码展示局部控制流。

## 公开 JSDoc 包含失败

**过度删减：**“返回 realm 全局对象。”

**平衡版：**“返回已初始化 realm 全局对象。初始化未完成或 realm 已释放时抛错。”

**过度详细：**通向每次抛错的内部状态机分支及准确辅助调用。

抛错及状态前提是调用者可见约定事实。

## 保留简明实现映射

**过度删减：**“由外部 API 支持的搜索提供者。”

**平衡版：**“把每个提供者结果映射到共享搜索结果字段，保留标题、URL 及文本，省略提供者专用排名元数据。”

**过度详细：**逐字段重述映射代码，包括同名字段及显然赋值。

保留解释适配器丢弃或改变信息位置的映射细节。

## 链接理由，保留局部约定

**过度删减：**“释放见生命周期 Agent Note。”

**平衡版：**“释放中止运行并等待提供者静止。责任归属及竞态处理见生命周期 Agent Note。”

**过度详细：**每个释放器旁重复 Agent Note 的 Promise 编排及被拒责任模型。

在调用者需要处保留行为及完成保证。算法与理由积极链接；链接不能替代局部约定。

## 已实施 Agent Notes 保留验证约定

**过度删减：**因 Agent Note 已交付而删除整个 Testing 节。

**平衡版：**“单元测试覆盖发布前后取消、释放静止及提供者重载。构建入口冒烟覆盖真实加载器路径；因传输为进程专用，快照覆盖延后。”

**过度详细：**逐文件走读夹具及断言，无额外行为区别。

删除迁移任务及测试叙述。保留层次、固定行为、真实入口及明确覆盖缺口。

## 安全边界可能需一个具体示例

**过度删减：**“挂载插件共享 Host 权限。”

**平衡版：**“挂载插件共享 Host 权限；例如访问 `ctx.shell` 可按 Host 执行器权限执行命令。”

**过度详细：**列举插件可能滥用的每项服务及每个假设漏洞。

一个示例能让抽象安全限制在操作上清楚时，保留它。

## 完全删除推理记录

**过度详细：**“循环先检查值是否缺失。缺失则下一分支提前返回。否则继续，所以最后断言安全。”

**平衡版：**代码已表达分支则不写注释。提前返回保护非显然不变量时，只陈述不变量。

不要把推理记录压缩成更短叙述；删除它。

## 配置注释解释树无法表达的内容

**过度详细：**相邻条目已显示顺序，却说“此条加载本地文件系统提供者，接着策略插件，再是 read、write、edit 工具”。

**平衡版：**“策略先于模型可见工具加载，使其 write 与 edit 调用经过先读后改门禁。”

保留顺序后果、出人意料的范围规则或安全边界。配置自己展示清单。

## 不只为字数删减

**当前：**“适配器将提供者错误转换为共享错误类型，使调用者能统一处理认证、限流及瞬态失败。”

**更短但更差：**“适配器规范化提供者错误。”

**平衡决定：**除非链接或周围约定已列失败类别，否则保留当前句。短版丢后果及区别，未改善结构。

## 模型可见文本遵循责任归属

**过度删减：**“调用失败时工具返回错误。”

**过度详细：**把另一包的模式及渲染字符串复制进此后端 README。

**平衡版：**引用本包负责的稳定提示、结果及错误文本。模式链接生成工具目录，其他包负责的文字链接消费者 README；局部只说本包条件或差异。

到达模型的措辞是行为，但重复仍会漂移。准确性归负责者。

纯文字审计可识别可疑措辞，但没有负责的可运行快照时不得悄改。保留并报告延后，或扩大授权变更，包含负责场景及必需 GUI 证据。

## 生成概要必须独立成立

**过度删减：**“批准请求及策略服务。”负责者稍后解释策略顺序及审计日志，但目录仅导出首句。

**过度详细：**将完整生命周期及提示通知行为搬进抽取句。

**平衡版：**“批准服务在回答者之前应用会话策略，并把每对请求／结果记录到发起请求的会话。”非目录细节留后句。

了解生成器抽取什么。该片段必须保留生成输出需要的约定。

## 限制是约定，不是债务清单

**过度删减：**省略让配置变化必须重载插件的进程生命周期缓存。

**过度详细：**列举私有辅助清理及未使用测试专用访问器，对调用者或维护者没有后果。

**平衡版：**“提供者选择按插件生命周期缓存；安装或修复提供者需重载。”普通清理留 TODO 或 Agent Note。

保留影响使用或安全维护的缺口及非显然约束。包 README 不是积压转储。
