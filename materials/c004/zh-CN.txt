# AGENTS.md — 已实施 Agent Notes

这些 Agent Notes 描述已经交付的决策。遵循[根指令](../../../AGENTS.md)、[文档标准](../../../docs/AGENTS.md)和 [Agent Note 格式](../README.md#the-file-format)；`verify-agent-note-format` 检查与生命周期对应的结构。

## 让已实施 Agent Note 与实际交付保持一致

路径、符号、默认值和机制发生变化时，在同一次变更中同步更新。直接改写过时事实，不追加变更历史。

已交付笔记不太可能指导未来工作时，通过 [`dsh-archive-agent-notes`](../../skills/dsh-archive-agent-notes/SKILL.md) 归档完整三文件组，不继续维护。

### 这不意味着可以重写决策本身

事实实现原地更新。反转决策或其理由，必须新建 Agent Note 并交叉链接；完全被替代的旧笔记只能依据 [Agent Note 规则](../README.md)中的合并规则删除。
