# 测试行为，而非实现

测试是一项关于代码使用者通过接口能观察到什么的主张：返回值、错误、可回读的状态，以及对外部系统的影响。私有辅助函数、内部调用顺序和中间数据属于实现。

用两种设想的修改判断每个测试：

- **破坏行为**（返回错误值、跳过副作用或重复副作用）。测试仍通过就没有证明任何东西。常见原因是断言宽松、期望值由被测代码计算，或断言的数据是测试自行构建的。
- **改变内部实现**，同时保留每项可观察结果。测试失败就说明它绑定了实现。

保留能捕捉第一种修改、又能承受第二种修改的测试。其他测试重写或删除。用具体输入经公开接口驱动代码，根据要求推导期望值。外部服务接收到什么属于行为；内部辅助函数被调用不属于行为。“这件事绝不发生”要配一个它确实会发生的案例。断言调用者据以分支的错误类型，而不是消息文字。
