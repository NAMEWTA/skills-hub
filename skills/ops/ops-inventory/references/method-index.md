# 本技能的方法与资源

按当前问题读取，不要求每次初始化全部清单。

- [运行关系模型](runtime-model.md)：实体、稳定身份、来源和一致性。
- [发现与核验](discovery.md)：已有资料、受限发现、SSH 与既有运行工具。
- [双向查询与影响分析](queries.md)：机器、项目、共享服务及变更影响。
- [两个项目与共享服务示例](example-topology.md)：多对多、未知对象、消费范围与反例。
- [运行关系模板](../assets/registry.md)：按实际资料裁剪的登记模板。

通用执行和记录调用 `ops-execute`，健康采集调用 `ops-inspect`，历史查询调用 `ops-history`；本包不复制其方法。
