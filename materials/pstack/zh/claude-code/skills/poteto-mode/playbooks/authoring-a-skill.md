### 编写或修改技能

**你负责技能的表达方式。**

1. 使用 **create-skill**，即 Cursor 内置的 SKILL.md 编写技能。
2. 验证技能：frontmatter 含 `name` 和 `description`，引用文件存在，跨技能链接可解析。
3. 结构性变化编写检查用例，主观性变化跳过。
4. 执行 **Opening a PR**。

拿不准时删除。只保留会改变决策的文字。告诉它做什么，省去理由；只有没有理由就难懂时才解释。语气与范围匹配。按 **encode-lessons-in-structure** 原则指向结构化来源，如类型、README、配置。通过路径委派其他技能，不重复叙述。反复遇到却未记录的工作流，应提出新增技能。

**回复：** 技能摘要、关键设计决策、验证说明。
