# Agent Note: 将未来价值较低的 Agent Notes 冻结到活动资料集之外

Status: implemented

英文 | [中文](2026-07-26-frozen-agent-note-archive.zh.md)

## 问题

已实施 Agent Notes 作为当前决策记录持续维护，所以活动资料集中的每个路径、符号、默认值、译文、代码围栏、包引用和出站链接都带来维护义务。理由仍能指导未来工作时，这个成本合理；对于已经结束的界面细节、小修复、被替代的实现动作，或当前权威记录已在别处的流程历史，这个成本不合理。删除所有低价值已实施记录会抹去有用的历史证据，而保留每个已拒绝提案会保存既不再合理、也没有教育意义的想法。资料集需要一条保留边界，区分活动指导与冻结历史，并且不把归档变成另一层维护负担。

## 决策

只描述小型界面调整或纯机械性变更的已实施笔记，连同完整三文件组一起删除，并修复或移除入站链接。小型实现仍可能承载长期的命名、兼容性、责任或行为决策；这些记录仍有资格保留。只有其他已实施 Agent Notes 可以归档：交付决策已完成，其理由不太可能指导未来工作，同时仍有历史决策价值。基础边界、持久化与传输语义、安全规则、反复出现的设计诱惑，以及尚未解除的重新引入条件，无论年代或字数都保持活动。提议中笔记不进入归档；过时提案变为已拒绝。已拒绝笔记只在能阻止有诱惑力、有意义的错误选择时保留，否则删除完整三文件组。

归档路径为 `.agents/notes/archived/{kind}/yyyy-mm-dd-topic.md`，省略冗余的 `implemented`。归档变更移动完整英文、中文和一致性附属记录三文件组，保留 `Status: implemented`，并在两个语言文件紧接其后插入 `Archived: YYYY-MM-DD`。只允许搬迁、这行元数据、相应附属记录重录，以及机械的入站链接修复。归档准入检查生命周期元数据与完整性，不检查标题标点、空行布局或语言切换文字；要求修复这些内容会改写历史记录。

根 `.rgignore` 将归档排除在遍历父目录的搜索之外。历史查询显式指定归档目录，因此仍能主动访问历史，同时不把冻结事实混入活动决策搜索。

归档后，三文件组永久冻结，作为历史背景而非当前权威依据。不为包重命名、行为变化、翻译标准、格式规则、失效出站链接或后来的文档约定更新它。活动正文可以有意链接到归档笔记、将链接重定向到当前权威记录，或删除链接。因此仓库检查验证指向归档文件的链接，但不把归档文件作为链接来源。

[`verify-archived-agent-notes`](../../../../scripts/verify-archived-agent-notes.ts) 负责冻结边界。它只接受封闭的 Agent Note 类型集合，要求完整三文件组、已实施状态、相同且有效的归档日期，核对附属记录与两个当前 Git blob 哈希，并在只追加清单中按路径与 SHA-256 内容哈希封存每个产物；只有[归档说明](../../archived/AGENTS.md)记录的精确封存转换例外被允许。`--write` 模式先证明所有已有封存未变，再仅追加新归档产物。PR CI 提供可信基准 SHA，并在运行校验器前检出完整历史，避免复用运行器的浅检出遗漏基准清单。普通 Agent Note 格式、翻译配对、换行、Markdown 链接、包路径、Mermaid、文档 TypeScript 和类型等价检查排除归档来源；这些检查的标准演进不能形成修改历史的压力。

[`dsh-archive-agent-notes`](../../../skills/dsh-archive-agent-notes/SKILL.md) 工作流负责分类。它要求逐篇进行语义审计，通过代码和当前文档判断当前权威记录，只把字数用于初筛，提供经过校准的保留、归档、删除示例，并报告真正难以取舍的结果供评审。

替代关系在新 Agent Note 撰写时检查，不延后到将来的资料清理。作者比较新笔记与覆盖同一决策、机制或被拒绝方案的活动笔记，并分类每个完全替代或部分替代。符合条件的已实施三文件组在同一个 PR 中归档；部分替代和有独立价值的理由保持活动并交叉链接；提议中与已拒绝的匹配项遵循各自生命周期规则。

## 考虑过的替代方案

**删除所有离开活动资料集的笔记。** 拒绝，因为已实施记录即使对未来指导有限，也可能提供关于已结束决策的有用历史证据。封存内容的归档能保留这些证据，同时不假装它们仍然有效。

**让所有已实施和已拒绝笔记保持活动。** 拒绝，因为不再帮助未来决策的记录会增加维护工作与搜索噪声。已拒绝笔记尤其只有能阻止合理误判时才值得保留。

**让归档笔记继续出现在默认仓库搜索中。** 拒绝，因为归档事实按设计可能过时，却可能因词面匹配排在当前结果前面。历史工作可以显式搜索归档目录。

**把替代关系清理推迟到周期性的全资料审计。** 拒绝，因为替代笔记的作者掌握最新的归属与重叠证据。推迟会留下冗余的活动权威记录，并让后续分类更昂贵。

**也归档已拒绝或提议中笔记。** 拒绝，因为归档表示“已实施的历史决策”。过时提案需要明确拒绝；没有防误用价值的拒绝记录应删除，不应进入第二个低价值存放区。

**继续对归档笔记应用全部文档检查。** 拒绝，因为后来的格式、翻译、代码、包或链接规则会迫使重写历史快照。专用校验器负责完整性与不可变性。

**只冻结理由，允许刷新事实。** 拒绝，因为这会重新引入活动资料集的判断与翻译负担，并让哪些句子属于历史变得不清楚。当前事实应放在活动文档或新的活动 Agent Note 中。

## 后果

活动资料集成为预计会影响未来工作的决策集合；未来指导价值较低、但具有实质历史意义的决策，仍可显式搜索与链接，同时不消耗维护注意力，也不出现在父目录搜索中。撰写新笔记包含范围明确的替代关系检查，避免替代决策悄悄留下冗余活动记录。拒绝记录不再保护有意义的选择时可以删除；提议中工作不能通过归档悄悄逃避结论。归档增加一份清单、一个专用校验器，以及明确的一次性元数据步骤。归档事实与出站链接按设计可能过时，因此读者与 Agent 必须将活动代码和文档视为权威，并只把归档笔记作为历史引用。
