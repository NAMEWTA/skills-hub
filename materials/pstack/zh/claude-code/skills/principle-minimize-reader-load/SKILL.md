# 降低读者负担

读者负担是理解代码需要付出的工作。它有两个独立维度：从问题追到答案需要穿过多少层，以及头脑中要保留多少隐藏或可变状态。两者都要控制。

- 折叠只做转发的层：只有一个调用者的包装、没有第二种实现的适配器、直接透传的方法。将它们内联。
- 缩小状态范围：返回值优于修改，局部变量优于字段，字段优于模块状态，模块状态优于全局状态。通过推导取得值，而不是同步多份状态。
- 在边界说明一次不变量，不在每个消费者中重复。

检查：新读者能否在 30 秒内回答“X 从哪里来？”和“什么会改变 X？”如果不能，就减少层次或状态。
