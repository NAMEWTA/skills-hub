# Home 资料

- home-setup 管理项目登记、地图、本机路径及派遣方式与 team。
- home-map 管理 relations.md。
- home-knowledge 管理 notes/、inbox/、archive/notes/、exclusions.md 及知识索引。
- home-history 管理 history/、archive/history/ 及历史索引。
- home-workflow 协调派遣与验收，home-tasks 管理 coordination/ 的主题、回执、占用和状态。
- home-route 定位，home-integrate 协调联合验证，home-doctor 只读诊断。

资料按需建立。项目内部资料和再派遣由当地 Agent 管理。用户选择决定工具与配置，实际投递状态由原方法核查。

自定义规则放根 AGENTS.md。
