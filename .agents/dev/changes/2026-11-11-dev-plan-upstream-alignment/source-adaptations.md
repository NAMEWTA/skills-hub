## 独立来源复核的处理

首次复核报告见 source-review.md。审阅者只收到五份直接来源、运行包和两份项目约定，未收到 skill-authoring、历史适配清单和本次已批准计划，因此报告中的前两类机械差异须结合实际本地约定判断：

- 十通道/验证适用性和单任务单文件：确实偏离上游原样，但属于已有且有明确项目规范的适配；保留原文底稿、完整模板与十个槽位，补记依据，不宣称未经修改。
- PR ready/draft：接受收窄建议，恢复就绪默认；例外来自用户/项目明确要求，或 a012 等已选完整执行方法的明确约定。
- 范围外问题必须已关闭：接受并直接修正正文与模板注释，未关闭事实可以引用但不在本次前沿。复核又发现“目前决定”的已关闭标题遗留，已改为已解决问题；这是授权适配的口径同步，没有改变答案索引结构。

本轮不因审阅意见重复复制其他技能的方法，也不为迁就固定脚本强制每项十代理或单文件。最终内容仍需按本次范围验证，来源复核不等于生成效果或真实交付已经通过。
