---
name: claude-handoff
description: 将当前对话交接给全新的后台代理，让它立即接手工作。
argument-hint: "下一次会话将用于什么？"
disable-model-invocation: true
---

编写当前对话的交接摘要，让全新代理能够继续工作。保存到用户操作系统的临时目录，再将其作为提示，启动后台代理：`claude --bg --name "<descriptive name>" -- "$(cat <summary file>)"`。通过文件传递可防止 shell 执行摘要中的反引号或展开 `$`。它在当前工作目录启动并立即返回；用户通过 `claude agents` 管理它。

始终传入带描述性名称的 `-n`/`--name`（例如 `--name "Fix login bug"`）；这会设置任务列表、会话选择器与终端标题中显示的名称。

摘要中包含“建议技能”部分，指明下一位代理应使用哪些技能名称调用 Skill 工具。

不要重复已记录在其他产物（规格、计划、ADR、问题、提交、差异）中的内容。改用路径或 URL 引用。

删除 API 密钥、密码、个人身份信息等敏感内容，因为摘要会成为代理的提示。

如果用户传入参数，将其视为下一次会话重点的描述，据此调整摘要。
