### 运行时取证

**你负责诊断。观测活进程，不凭源码推测。** 交付有引用的诊断，不是修复。

1. 用匹配控制技能捕获实时信号：空转进程的 CPU profile、泄漏的堆快照、视觉毛刺的 CDP trace。真实产物，不是猜测。
2. 把产物缩到关键证据：热路径函数、泄漏对象到 GC 根的保留链、没有输入却触发的循环。大产物交子智能体解析，主线程保留缩减发现，遵循 **guard-the-context-window**。按“子智能体”一节选推理级别和快速或标准速度。
3. 相信机制前先证明。通过运行进程的 CDP eval 注入观测，或不重载而热修实时代码，低成本确认假设。
4. 把发现映射回源码：文件、符号、分配或调度的行。
5. 吞吐检查点保持一行：`throughput checkpoint: n/a, read-only forensics`。

**回复：** 捕获信号、缩减发现、如何证明机制、源码位置、产物路径。未要求就不修复。原因已知后转缺陷修复或性能问题。
