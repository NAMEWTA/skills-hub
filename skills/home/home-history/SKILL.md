# Home 历史与接续

说明当时发生了什么、为何决定、实际结果与证据在哪。历史是带来源的摘要，当前结论与运行状态继续由原 owner 维护。选择用户明确的 Home 根，按任务读取所需范围。

## 按任务读取

| 任务 | 方法或资源 |
| --- | --- |
| 记录事件、查过去理由、准备回顾、修订或忘记摘要 | [历史维护与检索](references/history-method.md) |
| 记录、去重、修订、日期查询及重建导航 | [历史工具参考](references/tools.md)，使用 [history.mjs](scripts/history.mjs) |
| 新建有价值事件 | [事件模板](assets/event.md) |
| 凭资料继续工作或交回原任务 owner | [接续说明](assets/resumption.md) |

## 执行

1. 确认用户要查当时理由、保存事件、回顾某段时间，还是继续已有工作。先复用已知项目、主题和时间范围；普通查询不强制写一篇新历史。
2. 按主题、repo ID、日期与关键字查 Home 正文，必要时打开相邻事件和已授权原件。索引缺失或截断时回到目录和文本检索，报告实际覆盖。
3. 记录前确认 owner、来源身份和实际结果。同一来源的同一事件重导更新原记录或保持不变，真实后续事件可新增。只凭相似标题不合并，不把取消、中断、失败或部分结果写成完成。
4. 按事件模板保存发生时间、必要整理时间、范围、当时理由、结果、未决项与来源。时间不明保持不明，摘要不冒充原始 transcript，文件 mtime 不替代事件时间。
5. 当前结论需要改变时交 `home-knowledge`，用户默认需要改变时交 `home-setup`。本技能只更新其历史资料，并修复有关导航；跨 owner 请求继续完成已授权范围。
6. 用户要求继续时，从实际可读资料生成简短接续说明。若涉及原派遣任务，交 `home-workflow` 调用原方法核查当前实例和任务；不能仅凭“昨天未完成”重复派发修改。
7. 读回记录、时间、身份和结果后报告；来源不可达、只剩摘要、索引失败或检索不完整分别说明。

## 范围与完成条件

本技能维护 `.agents/home/history/`、`archive/history/` 和历史导航。采用每个事件一个文件，保留 stable event key、来源与实际 scope；不建立中央 session/tasks 账本，不扫描宿主私有 history，不同步厂商记忆存储。

忘记按授权处理历史、归档和派生入口，来源排除由 `home-knowledge` 维护。本技能读取排除依据，避免已删除内容通过重导或新摘要复活；不以审计名义再保存被要求忘记的正文。

新会话可以读取 Home Markdown 重建有关上下文，这与原生 resume 是不同结果。日周回顾和任务末回顾按当前请求或用户已经明确的约定执行；文档、安装和普通查询不会创建 daemon 或定时任务。
