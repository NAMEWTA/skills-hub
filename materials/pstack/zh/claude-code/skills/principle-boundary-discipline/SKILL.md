# 边界纪律

在数据跨越系统边界时验证、收窄类型并处理错误，例如 CLI 参数、配置文件、外部 API 和网络。内部信任类型：不重复验证，不做多余的 nil 检查。在边界把原始数据解析成领域类型，不让传输和框架类型进入公开接口。业务逻辑放在不依赖框架的纯函数中。调用它们的外壳保持轻薄。

做两个检查。数据现在是否正在跨越边界？如果不是，验证就是多余的。它是否能变成只由外壳调用的纯函数？如果能，就提取出来。
