# 运维资料

这里保存服务器、服务与项目运行关系及操作事实；统一入口是 `ops-workflow`，明确任务可直接使用对应 ops 技能。

- `./registry/`：身份、运行组成、依赖、来源与核验时间。
- `./runs/`：同一任务的请求、步骤、后端证据和结果；执行与记录由 `ops-execute` 维护。
- `./projects/`：项目运维知识；已有权威资料按真实位置引用。
- `./incidents/`：跨 run 事件；`./lessons/`：经验候选；`./index/`：可重建查询索引。

业务目录按需建立，不把导航当现场事实。凭据只留引用。部署发布归项目；其他领域独立，不写入其资料。安装器会更新本导航，自定义规则请另存。按任务显式读取相关资料，不假定宿主自动递归加载。
