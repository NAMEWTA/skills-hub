# Home Git 跟踪与新机恢复

[需求与确认决定](source/request.md)来自 Home 初始化与换机设计对话。

- `home-setup` 显式初始化独立 Home 的本地 Git，并确认默认跟踪面。首次暂存、提交和同步按用户指令执行。已有 Git 只读核验。
- 基线包含根导航、`.agents/` 中各领域的正式文档和完整安装技能。项目仓库、本机配置、凭据和运行原件各留原处。
- 新机从同仓技能恢复登记项目。默认检出主远端默认分支，有匹配 checkout 就复用。一个目标失败后继续处理其他目标。
- 正式文档正文保存结论、理由、关键观察与接续条件。使用没有原件和旧配置的新克隆验证历史、知识、任务可用。

实施清单见 [01 Home Git 与换机](tasks/01-home-portability.md)。
