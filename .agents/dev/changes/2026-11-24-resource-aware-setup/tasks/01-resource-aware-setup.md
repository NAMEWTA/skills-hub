# 01 资源初始化与团队配置

规格：[brief.md](../brief.md)。来源：[research.md](../research.md)。

交付：环境与资源评估成为 dev-setup 的初始化主线，相关技能消费同一预算；已合并 worktree 按现有入口核实进程和磁盘释放；团队文件由用户显式选择。

直接依赖：无。

边界：不新增宿主调度服务，不覆盖用户历史配置，不改非 dev 领域能力或上游固定来源版本。

## 验收

- [x] 环境资源、未知容量、共享池、峰值预留、三类上限、复测和零准入规则完整且可应用。
- [x] 执行技能没有仅以工具上限或最大并发派发的反向指令。
- [x] 新团队模板及方法包内可达，阶段不自动读取旧角色文件；历史迁移目标和材料映射有效。
- [x] 清理能区分错误父分支、PID 复用、自己的残留服务、手工锁和未保存文件。
- [ ] 结构、真实包装与跨平台 CI 通过；main 和补丁发布对应已验证版本。
