# Git 冲突处理

读取[冲突定位、解决和验证](references/resolve.md)。接收实际工作树、在途操作、两侧提交、行为契约、验证要求以及提交或继续操作的授权。先核对仓库、索引、现有修改和参与者，沿用当前 change 的证据。

按文件查明双方意图，解决冲突并验证组合后的行为。将已处理路径、暂存检查、测试和未决事项交回调用者。由 `dev-worktree` 调用时，将已验证的暂存结果交集成者生成并核对双亲提交。独立接手时，只有授权包含完成原操作才按对应命令继续。
