# RESOURCES.md 格式

`RESOURCES.md` 是此主题精选的可信来源集合。讲解知识应取自这里，而不是模型参数中的猜测。智慧来自这里列出的社群。

## 结构

```md
# {主题}资源

## 知识

- [书籍：Zatsiorsky 与 Kraemer 著《力量训练的科学与实践》](https://example.com)
  关于训练计划编排与适应的基础著作。适用：周期化、恢复、强度区间相关的一切。
- [文章：Greg Nuckols（Stronger By Science）《我应该训练多少？》](https://example.com)
  基于证据的训练量标志性区间综述。适用：各肌群每周组数目标。

## 智慧（社群）

- [r/weightroom](https://reddit.com/r/weightroom)
  高信噪比 subreddit，管理者抑制健身伪科学。适用：训练计划评议、平台期排查。
- 本地：{健身房名称}周二力量课
  适用：动作的实时教练反馈。
```

## 规则

- **仅限高可信来源。** 优先一手来源、公认专家、同行评审研究，以及管理严格的社群。如果资源是披着教育外衣的营销，排除。
- **每条都注释。** 裸链接三个月后就没用。加一行：涵盖什么、何时使用。
- **按知识/智慧分组。** 与 [SKILL.md](./SKILL.md) 的理念对应。某资源只属于一组也没问题。
- **明确指出空缺。** 使命需要的领域若没有好资源，写 `## 空缺` 列明缺什么，以驱动后续搜索。
- **果断修剪。** 证明错误、浅薄或偏离使命的资源，应移除而非埋起来。五个精良来源胜过三十个平庸来源。
- **记录社群偏好。** 用户不愿加入社群时，在这里注明，避免未来会话反复提议。
