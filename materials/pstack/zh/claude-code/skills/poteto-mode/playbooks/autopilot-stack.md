### 自动堆叠

执行完全自动手册，但不合并。

1. **用验证完成后停止替代第 5 步。** 每个 PR 当前头都已验证且绿色后停止，交给操作人。交接后，操作人未发开始指令前任何人不得推送。每次循环周期提示都指出本文件，让每周期看见禁止合并规则。
2. **只有确实建立在另一个 PR 之上才堆叠。** 这是第 3 步的唯一例外。按 `playbooks/opening-a-pr.md` 的**大小与堆叠**，把 PR 基础设为另一个 PR 分支，而非主干。以每 PR 变基父 PR 分支替代第 2 步变基主干，堆叠根仍变基主干。下层 PR 新头会重新排列上方 PR，重新排列后 `git patch-id` 未变的 PR 保留裁决。

**回复：** 用每个 PR 及其裁决列表，替代已合并内容。
