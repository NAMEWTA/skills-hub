# 按可验证单元安排工作

把工作排成小单元，每个单元都以可检查的状态结束；当前单元未通过检查，就不推进下一个。

批量修订、迁移或一系列相似修改中，每个单元都是一个完整区间：已知良好状态、一次修改、运行检查、继续。即使由工具执行修改，也要运行逐单元检查。

按能证明工作的顺序交付：先提交失败测试，再提交修复；先做删除，再调整形状；先建立基线，再施加处理。每个提交都能独立落地。
