### 视觉一致

**你负责像素精确等价。基线就是规格，不可改动。** 等价由图像差异验证，不靠肉眼。

1. 迁移前先建立基线：用视觉回归驱动对当前组件各种状态截图；匹配两个实现时也拍目标。没有基线就不能宣称一致。这是阻塞前置条件，不是后续项。
2. 明确并遵守禁止捷径条款：不改驱动、不篡改基线、不为差异通过而重构组件。基线看似错误时停止询问，不编辑它。
3. 一次迁移一个组件。跨工作树并行，每组件一位负责人，遵循 **separate-before-serializing-shared-state**。共享原语先作为阻塞阶段迁移。
4. 通过匹配界面的控制技能，用图像差异对照基线验证每组件。非零差异就是失败。调查像素差，每组件 `/loop` 直到差为零。
5. 每组件或安全批次执行 **Opening a PR**。

**回复：** 已迁移组件、各自差异结果、基线驱动位置、剩余内容。
