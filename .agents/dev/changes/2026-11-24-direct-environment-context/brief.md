# 开发技能直接使用环境事实

用户指出 v0.1.28 的其他开发技能仍要求读取或调用 `dev-setup`。本次修正适用于整个 dev 运行域的入口、参考、帮助和模板：需要环境或资源信息时直接复用 `.agents/dev/context/environment.md` 或已有权威位置中有效的内容；缺失或过期时依据当前实际执行主机与任务判断。

其他技能不再提及 `dev-setup`，也不以创建环境文档或完成初始化为前置。保留资源不足排队、共享预留、嵌套任务额度、原有方法的独立性与覆盖，以及已完成 worktree 的现有清理方法。环境评估技能自身保留名称、发现元数据和完整容量方法；历史来源与发布记录保留。

用户此前已授权推送 main 并增加补丁发布，本次沿用该授权。起点为 main `5a8a5cb2f0ae3d52b6d41555c07f2dd9bd8e4f07`、正式版本 `v0.1.28`，目标版本 `v0.1.29`。

验收以完整 dev 运行内容和真实隔离安装后的文件为准，核对从上一版本升级的结果。当前本地只有部分仓库物化；完整仓库与真实 npm 分发检查由现有跨平台 CI 在固定提交执行。
