# 历史进展的取证资料

用户指定时间或主题且证据分散时，从[完整背景取证](context-recall.md)开始。只在本次授权的工作区与范围内检索；没有访问能力就标明缺口。这里的调查为进展报告提供依据，最终使用[进展回顾](status-report.md)组织变化与待决事项。

## 调查与综合

- [证据与可信度](evidence-confidence.md)：区分直接证据、推断和未知。
- [调查者简报](investigator-brief.md)：给出本次时间、主题、代码锚点和允许读取的来源。
- [综合方法](investigation-synthesis.md)：保留事实、反证、竞争解释和空结果，再提取报告所需结论。
- [来源选择](source-investigation.md)：依据真实连接器和读取能力选择下方手册。
- [事故与复盘背景](incident-investigation.md)：主题涉及回退、复发错误或防御代码时使用。
- [清晰写作](clear-writing.md)：写清已知结果、范围和下一步建议。
