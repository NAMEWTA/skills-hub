我想让这个任务更深入，而不是更庞大。改写之前，先做四件事：

1. 说出这个领域的顶尖专业人士会做、但我还没有要求的事情。
2. 指出他们会从什么最原始的材料开始，而不是从已经替我消化过的内容开始。
3. 指出他们会使用的具体方法和工具。
4. 说明除了你或我之外，什么能证明结果正确。

然后改写我的提示词，准确要求上述内容。

让改写后的提示词要求代理：凡是可以由实验判定的选择，都先制作原型，并根据观察结果推荐一个选项。无法通过实验判定的产品或偏好选择，留给我决定。
