# 删除其他阶段的模型配置提醒

用户纠正：其他技能直接不需要提模型规则或团队配置，不应改写为“按 dev-setup”；用户指定时自然构成本次任务上下文。完成修改后推送 main，再发布一个补丁版本。

基线：`09fb240b6ca76042b14773e06f283f8d2ea59ff4`，公开版本 v0.1.27；目标版本 v0.1.28。

## 交付边界

- 删除 `dev-setup` 外技能正文、帮助、路由及模板中的通用团队/模型配置、默认继承、模型选择和配置转介提醒，不添加新的否定式提醒替代它们。
- 用户明确引用的文件依当前任务上下文生效；团队文件的保存方法继续由 `dev-setup` 持有。
- 保留已要求的环境与资源预算、工作树回收、独立上下文、必要候选数量和盲评机制。
- 领域模型、TLA+ 模型、业务团队字段以及用户明确进行模型评测时的实验语义不属于配置提示，不按关键词删除。
- 同步来源适配、当前使用文档和安装器生成的导航；不改历史材料、来源固定版本或已发布历史记录。
- 沿用现有发布工作流，对最终版本提交完整验证后公开 npm 与 GitHub Release。

前次机制研究仍见 [resource-aware-setup](../2026-11-24-resource-aware-setup/research.md)。本轮为用户明确纠正下的局部删减，不引入新的方案或外部依赖。
