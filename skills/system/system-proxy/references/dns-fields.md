# DNS 字段与类型

这些说明帮助理解与核对配置。关于 `respect-rules`、直连解析和后缀处理的细节，采用 Mihomo v1.19.32 的行为作为已知线索；当前设备仍须检查版本、合并结果与运行日志。保持已有配置中的未知字段，不把示例变成全段覆盖。

## 字段责任

| 字段 | 负责什么 | 检查重点 |
| --- | --- | --- |
| `nameserver` | 普通域名默认解析 | resolver 身份、实际连接路径和代理组后缀 |
| `nameserver-policy` | 指定域名或集合的优先解析 | 是否覆盖默认选择，企业内部域是否需要保留 |
| `direct-nameserver` | DIRECT 业务的真实地址解析 | v1.19.32 不因 `respect-rules` 自动走代理；为空时回到主解析器，裸地址可能直连 |
| `default-nameserver` | 解析加密 resolver 主机名所需的引导 | 使用内核接受的 IP 形式端点，分别验证协议、证书与路径，不把节点例外扩成业务解析 |
| `proxy-server-nameserver` | 节点主机名解析 | 可否在隧道建立前到达；不能依赖尚未启动的同一节点 |
| `proxy-server-nameserver-policy` | 节点域名的专门解析策略 | 是否覆盖了通用节点引导规则 |
| `respect-rules` | 部分 DNS 列表未显式指定代理时依据业务规则选路 | 不等于强制代理；需可用的节点解析，不能假定覆盖 direct/default/proxy-server 列表 |
| DNS 地址 `#代理名` | 指定 DNS 连接的代理或组 | 精确匹配真实名称；未找到时可能按接口名解释；组名空格须正确编码 |
| `fallback` | 另一组解析端点 | 某些配置会并行发送，不是只有失败才查询；每个 resolver 都必须在选择范围内 |
| `fallback-filter` | 判断哪些答案需要回退 | 不用出口国家替代过滤条件；回退为空时核对过滤行为 |
| `enhanced-mode` | redir-host 或 fake-ip 等解析模式 | 地址映射、真实域名、规则与缓存兼容 |
| `fake-ip-filter` | 不使用映射地址的域名 | 局域网、企业域和平台连通性需求；不为隐藏地址随意破坏既有例外 |
| `dns.ipv6` | DNS 层的 IPv6 记录行为 | AAAA 与实际传输地址族分开；不能当作操作系统 IPv6 开关 |
| `listen` | 内核 DNS 监听 | 实际地址、端口、占用与权限；未验证不写系统网卡 DNS |

## 解析类型

下表的形式仅用于认识协议，尖括号内容是待替换参数，不可原样应用。

| 形式 | 传输或来源 | 关键限制 |
| --- | --- | --- |
| IP 地址或 UDP 形式 | UDP DNS | 不提供到 resolver 的内容加密；隧道内与本地物理外发要分清 |
| `tcp://<地址>` | TCP DNS | TCP 不等于加密，避免将节点引导例外扩成全部查询 |
| `tls://<地址>` | DNS over TLS | 校验 TLS、证书身份、端口与实际路径 |
| `https://resolver.example/dns-query` | DNS over HTTPS | 主机名引导、SNI、证书与路由分别处理 |
| `system` | 操作系统解析来源 | 可能回到 DHCP、VPN 或其他接口，不能默认视为已批准代理解析 |
| `dhcp://<接口>` | 接口 DHCP 提供的解析器 | 接口与租约会变；是否合适由具体网络目标决定 |
| `rcode://refused` | 内核返回拒绝结果 | 用于明确拒绝的方案，不能证明系统其他路径已被拦住 |

DoH 与 DoT 保护到 resolver 的内容，不隐藏全部连接元数据，也不自动经过代理。证书不支持某个数字地址时，不将域名端点生硬改成 IP。私有解析服务或企业 split DNS 应保留真实契约，不擅自替换为公共服务。

## YAML 与合并

字符串中 `#` 前的空白可能使余下内容被当成注释。即使源配置加了引号，也要检查客户端生成后的最终标量。组名里空格和符号的编码需符合当前内核与客户端，不能只看 UI 显示。

空 `{}` 可能表示“没有新增”，而不是“删除旧 map”；空列表也可能被 GUI 丢弃。按实际版本核对列表替换、map 合并、删除与优先级，重新读完整结果。某个字段存在于文件，不代表活动内核已加载。

完整形成方案及验证步骤见[DNS 工作流](dns-workflow.md)。
