# 杂项

我保留但很少使用的工具，不在插件中推广。

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)**：设置 Claude Code hook，在危险 git 命令（push、reset --hard、clean 等）执行前阻止它们。
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)**：把测试文件中的 `as` 类型断言迁移到 @total-typescript/shoehorn。
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)**：创建包含章节、问题、答案、讲解的练习目录结构。
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**：配置 Husky 提交前 hook，搭配 lint-staged、Prettier、类型检查和测试。
