# Home 资料

- home-setup 管理 repos.json、local.json 与 context/；项目地图按需查看，显式导出 repos.md。
- home-map 管理 relations.md。
- home-knowledge 管理 notes/、inbox/、archive/notes/、exclusions.md 及知识索引。
- home-history 管理 history/、archive/history/ 及历史索引。
- home-workflow 管理 coordination/ 摘要；home-route 定位，home-integrate 协调联合验证，home-doctor 只读诊断。

资料按需建立。项目内部资料由当地 Agent 读取，每层派遣记录归当地所选方法。用户选择决定工具与配置，保存不等于启动。历史不代替当前状态，跨 owner 更正和忘记由 workflow 协调。

自定义规则放根 AGENTS.md。
