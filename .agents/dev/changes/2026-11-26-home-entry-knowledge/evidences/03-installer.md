# 安装保留与按域选择验收

验收对应 [任务](../tasks/03-installer.md) 和 Issue #21 的 I01–I11。2026-11-26 在 Linux、Node.js v24.22.3 下运行，代码基于 `f23ba949826c4b6cac480280ff306cdd28681f39`。

## 实现结果

`scripts/init-persistence.mjs` 为 Home 增加确定性的基础区更新。仅接受唯一、完整、独占行且版本为 v1 的开始与结束标记，保留区外原始字节，包括 BOM、CRLF 和用户附加内容。普通正文提到标记名称不构成标记，实际保留注释仍按结构核验。

原 v0.1.35 的 11 行模板按固定 SHA-256 精确识别，原始模板保存在 `tests/fixtures/home-entry-v0.1.35.md`。只有原字节匹配时自动迁移；添加正文或改变换行的未标记文件均不被当作官方模板。未知版本、半截、重复、嵌套、逆序和非独占行标记在预检时报告 `HOME_ENTRY_CONFLICT`，主安装命令返回 1，整次选择零写入。

Home 更新复用原安装锁、写前版本比较、事务与回滚。其他 domain 仍按原固定模板合同处理。`cli.mjs` 在现有确认之前显示最终选择实际涉及的业务 domain，不增加确认步骤。普通安装继续不创建或修改根指令，也不因技能正文提到其他 domain 而安装它。
