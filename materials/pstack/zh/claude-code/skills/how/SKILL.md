# 如何运作

在 Claude Code 中，每个会话在遵循此技能前，先阅读一次 [Claude Code 适配器](../../docs/harness/claude-code.md)。它将 pstack 技能中的 Cursor 名称映射到 Claude Code。

探索代码库，回答“X 是如何工作的？”这类问题。

范围模糊时，说明你的理解并开始探索，用户可以调整方向。

## 1. 解释

启动一个 `subagent_type: generalPurpose`、`readonly: true` 的 Task 子代理，一次完成探索和解释。提供用户的问题以及以下任务说明：

> 你正在为资深工程师撰写架构说明。探索代码库，写出一份让不熟悉该领域的资深工程师读完后能够形成扎实心智模型的说明。读者应当充分理解架构，并能自信地开始在其中开展工作。你对代码库只有只读访问权限。

## 2. 呈现

呈现子代理的输出。可以为清晰度或补充对话中的上下文而做少量编辑，但不要大幅重写。
