# UI 对齐

在 [UI 开发循环](../SKILL.md#required-review-loop)中应用。对齐可比较的同级元素，包括可选图标和操作的预留槽位。

## 先布局结构，再视觉校准

区分点击目标、绘制出来的按钮、完整图标框和实际轮廓。图标有意保留的空白属于布局框；不要仅因绘制像素未碰到参考线就去掉它。扩大目标不得移动该框。光学校正之前，先检查容器、槽位、列、间隙及意外覆盖。CSS 框匹配，或仅把每个绘制轮廓对齐，都不足以证明平衡。

跨使用位置不一致的图形，应由图标负责者处理。某个组合专用的光学校正，需要限定范围的理由及与同级比较。保留预期层级：子图标可以与父文本对齐，但仅凭 DOM 嵌套不能决定缩进。比较裸图标与带边框控件时，额外命中内边距不算共享可见边缘。

内联 SVG 的 `vertical-align: middle` 依据字体基线／x-height，而非可见文本中心。跨中日韩文字、拉丁文、等宽字体和换行，检查字体、字号、行高及图标框。不要仅为居中图标而禁止多行链接换行。

## 同时选择对象和轴

指出对齐对象与参照容器。相等内边距不一定使文本起点对齐；相等 SVG 尺寸不一定使可见中心对齐。页脚操作旁的关闭控件，应明确选择控件边缘或完整图标框边缘；测量时不要在两者间切换。

| 对齐 | 用途 | 判断实际关系 | 常见错误 |
|---|---|---|---|
| 左边缘 | 导航标签、列表标题、字段标签、阅读内容 | 同角色文本沿一条有意选择的轴起始，包括跨组情况 | 每个组件有各自看似合理但彼此不同的内缩 |
| 水平居中 | 独立主按钮或短空状态堆叠 | 在具名容器内居中图标加标签的整体或完整堆叠 | 只居中标签，图标附在外面 |
| 垂直居中 | 单行图标／标签行或同级工具栏控件 | 可见中心平衡；完整可点击单元保持稳定高度 | CSS 等高掩盖 SVG 留白或行框差异 |
| 基线／首行 | 混合字号、带前置图标的多行标签 | 文本基线一致；图标归属预期首行 | 把图标居中在整个多行段落旁 |
| 双边缘 | 标题／操作行及输入器左右分组 | 左组沿内容边缘，右组沿尾部边缘 | 把每个图标分散铺满可用宽度 |
| 重复列 | 操作组、时间戳、文件行 | 对应槽位跨行共享中心或边缘 | 只有最后一个图标对齐，前面图标漂移 |

中英文导航按角色识别前置图标中心、文本起点及尾部控件。标题、头像与可展开搜索可不同。只在组合确立轴的地方延续它们，包括插件共享阅读边缘（即使悬停色块超出），以及对话／右侧栏的页头高度及基线。

触发器与菜单、或搜索框与结果行，比较完整文本内缩：外部内边距、边框、前置槽位及间隙。不同图标尺寸可以保持同一文本起点。相邻统计项移动图标前，应一起检查字体家族、字号、字重及行高。

按钮在自身边界内居中，欢迎组在主窗格内居中，空状态在标题／筛选器下方剩余内容区居中。固定顶部 margin 不等于居中。窗口过矮容不下整组时，以紧凑顶对齐布局保留滚动访问，而非裁切。

必要的小光学偏移之前，先统一同级控件尺寸和槽位；验证可比较的用法。保留可用且不重叠的命中目标，不通过 transform 掩盖父布局不一致。透明命中内边距可以超过绘制图标槽位；收紧操作组后检查相邻目标边缘。检查[间距](spacing.md)时不移动选定轴；不确定的判断查阅[案例](https://github.com/deepseek-ai/deepseek-harness/blob/e8f7b93a344964de3dca1ace9e72b6e4d6de87cb/docs/ui-design-review-cases.md#alignment)。
