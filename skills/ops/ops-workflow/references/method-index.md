# 方法与资源

本包只维护任务协调。按当前问题读取：

- [意图与路由](routing.md)：选择入口、咨询与实施、缺少能力时的处理。
- [任务与共享对象](coordination.md)：任务拆分、上下文、并行与项目 CLI。
- [接续与结果收束](continuation.md)：进展、暂停、旧任务与完整结果。
- [任务简述](../assets/task-brief.md)：复杂任务需要共享的上下文。
- [结果模板](../assets/result.md)：同一 run 的面向用户汇总。

执行与记录归 `ops-execute`；关系核验归 `ops-inventory`；历史查询归 `ops-history`；其他专门方法按入口中的技能名读取，不复制兄弟技能资源。
