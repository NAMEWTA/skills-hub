# 会话投影规则

## 概要

将可恢复的会话事实保存在 Projection 中，通过拥有它们的服务暴露。阅读 [API 与生命周期](https://github.com/deepseek-ai/deepseek-harness/blob/e8f7b93a344964de3dca1ace9e72b6e4d6de87cb/packages/session/session-projection/README.md)，了解受支持的准备、注册、读取和清理约定。

1. 所有持久化或可恢复的会话派生状态都放入 Projection，包括仅 Host 使用的状态。合适时复用已有拥有者。外部资源与进程级责任归属不放进持久化状态。持久化事实，而不是注册句柄、Promise 或运行资源。

2. 不把投影定义或句柄作为生产读取 API 暴露。就绪句柄保持私有；消费者使用拥有者服务的领域方法。句柄是进程内读取器，在激活时重新创建。服务依赖它时，必须要求 `sessionProjections`；只有可选贡献才可选注册。不要通过另一条恢复路径隐藏缺失的必需依赖。

   需要多个投影状态的运行时，接收一个由 `handle.readerFor(session)` 创建的有类型回调对象。通过增加属性扩展，而不是为每个状态新增构造参数或功能专用读取器。每个回调类型为 `() => S`；单一用途协作者直接接收该回调。这些 Host 状态读取器与传输快照及在线 Cordis Context 分开；不拥有注册、释放、缓存或 I/O。注册、Session 准备和句柄生命周期仍由各自拥有者负责。第 9 条定义同步 API 兼容性。

3. 通过 `init` 和 `apply` 恢复状态是同步且确定性的。不执行 I/O，不触发 Cordis 钩子、模型或工具。这些副作用由运行时钩子负责，回放不得重复执行。不相关事件返回相同状态引用。视图保持同步，可见值未变时保留其引用。

4. 持久化模式所接受的 JSON 状态。遵循 README 的状态版本与检查点水位规则。恢复检查点并回放其后缀，必须与完整回放一致。状态字段或恢复语义变化时修改版本；例外是可选新增字段：缺失时保留历史含义，且已有测试证明旧检查点后缀恢复与完整回放等价。仅仅通过模式验证还不够。

5. 优先固定大小或次线性状态。增长只有足够缓慢、仍可忽略时才可接受。必要的线性状态必须有当前用途，并明确内存、回放及单事件成本。不要习惯性保留与历史规模同阶的索引，包括事件序列集合。不要为了缩小体积而丢弃必需数据或改变行为。先做完整实现，再为具体需求优化。

6. 缓存必须能够丢弃并重建，且不改变行为。同步消费者需要引用的负载时，仅保存序列引用不够。在第 5 条限制内保存必需的当前值，或通过显式异步路径准备负载。不要把完整日志读取藏在缓存未命中里。不新增 `snapshotEvents`、`eventAt`、`ownEvents` 或等效包装：历史不必常驻内存。异步包装不会让同步历史读取变成异步。现有 Host 回放可为具名的受支持调用者保留，但必须有拥有者和移除条件；这并不允许[客户端缓存未命中时读取完整日志](https://github.com/deepseek-ai/deepseek-harness/blob/e8f7b93a344964de3dca1ace9e72b6e4d6de87cb/docs/defensive-patterns/conversation-and-session.md#cold-reads-are-the-last-resort)。删除被替代的恢复辅助函数；缓存重建不得重复恢复规则。

7. 暴露同步读取器或安装使用句柄的回调之前，等待必需注册完成，通常放在 `[Service.init]` 中。注册拒绝应让本次激活失败。等待期间可能有事件到达；只有为避免漏事件确有需要时才提前安装监听器。只在支持等待的回调中等待。不要机械地移动监听器或增加等待。保留 fiber 清理责任，等待显式释放，拥有者释放后不再创建副作用。

8. 将注册就绪与 Session 恢复分开。异步 Session 加载或准备的拥有者，在向同步读取器发布 Session 之前完成历史恢复。使用注册表支持的生命周期；不要给领域 getter 增加水合或隐藏 I/O。恢复准备状态，getter 读取状态。保留注册表对每个单元与 Session 的错误范围。

9. 切换读取路径之前，识别所有官方消费者，包括插件、CLI／GUI 和两套 SDK。在它们明确迁移前保留同步调用者；Promise 无法实现同步 API。新增必需服务或激活步骤需要更新消费者及升级指南。兼容性围绕真实受支持调用者，不围绕仅测试使用的组合。

10. 经由受影响的真实入口，验证值、通知、错误范围与时序以及恢复。保留已有行为断言。不要把仅消费者使用的错误移到急切的 Projection 处理过程。生命周期变化要测试延迟注册、拒绝、替换及等待期间释放。使用实际 Session／存储生命周期和显式屏障，而非不完整的 Session 模拟或微任务计数。除释放状态外，也检查错误日志。恢复测试覆盖可用、缺失、不兼容的检查点及后缀回放，且不得产生运行时副作用。
