### 自动堆叠

执行完全自动手册，但不合并。

1. **用验证完成后停止替代第 5 步。** 每个 PR 当前头都已验证且绿色后停止，交给操作人。交接后，操作人未发开始指令前任何人不得推送。每次循环周期提示都指出本文件，让每周期看见禁止合并规则。
2. **只有构建在另一个 PR 之上的 PR 才形成堆叠。** 这是第 3 步的唯一例外。按照 `playbooks/opening-a-pr.md`，将 PR 的基底设为另一个 PR 的分支，而不是 trunk。第 2 步中 rebase 到 trunk 的要求改为：每个 PR rebase 到父 PR 的分支，栈根 rebase 到 trunk。下层 PR 出现新 head 时，对上层 PR 重新堆叠；若重新堆叠后某个 PR 的 `git patch-id` 未变，则保留其原有结论。

**回复：** 用每个 PR 及其裁决列表，替代已合并内容。
