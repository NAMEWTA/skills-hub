# 为领域建模

用数据结构表达领域，而不是把它分散在条件语句中。正确的结构让非法状态无法表示，并消除分支。

用状态机替代散落的布尔值或阶段检查，用有类型的模型替代松散参数，用映射、注册表或可辨识联合替代分布在文件间的分支，用 reducer 替代临时拼凑的修改，并在访问模式需要时使用索引、队列或规范化集合。

不要强行抽象。现有形状清晰、局部且不太可能增长时，保留朴素代码；警惕增加间接层却不能减少分支或非法状态的抽象。

跳过本原则的迹象：一个功能让既有 if/else 链又长出一个分支，或增加了必须与第一个布尔值保持同步的第二个布尔值。
