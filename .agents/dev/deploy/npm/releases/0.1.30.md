## 发布范围

新增八个自包含中文 Home 技能，覆盖配置、项目登记与真实 checkout 定位、各层负责人协作、关系、现行知识、历史、联合验证和诊断。业务资料归 `.agents/home/`，各项目继续使用当地规则和记录。
