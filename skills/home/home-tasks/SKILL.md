# Home 派遣记录

按[记录与操作](references/records.md)使用包内 `scripts/tasks.mjs`。开始前确认 Home 根与真实主题；一个业务目标可覆盖多个项目，同一目标的来回消息沿用主题。只收录 Home 直接派出的项目任务和已收到的回执。

1. 查询时使用 `list`、`show` 或 `project`，按最新证据解释待派发、进行中、受阻、待核实或结案。查询零写入，旧 TSV 只是导航。
2. 接到已授权的项目任务时创建主题，再写派发消息，允许目标在未派发时排队。Home 发布 task 和 report，各自按主题独立编号。项目 Agent 的提问、进度和交付来自实际派遣方法。
3. 通过 `reserve` 原子检查项目占用并记录本次准备投递。让 `home-workflow` 按所选方式真正发出，收到证据后更新各目标。结果不明时保留占用，交原方法核实。
4. 保存证据并更新实际状态。只有 Home 验收或确认取消后才释放对应项目；主题需要共同验收时，等组合结果满足条件再结案。

完成后给出主题、最新 task/report、状态和证据指针。工具不启动 Agent，也不控制项目下一级任务或后台会话。
