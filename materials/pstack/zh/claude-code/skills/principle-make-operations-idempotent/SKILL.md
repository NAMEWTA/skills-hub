# 让操作幂等

设计每个改变状态的操作，使它无论执行多少次、上次停在哪里，都能收敛到正确状态。

每一步依据实际存在的状态，而不是上次运行打算做什么。读取当前状态，与目标比较，只应用差异。

一次运行留下的任何东西（锁、临时文件、写到一半的记录、已认领任务），都必须能让下次运行判断是否失效；判断依据要在上次可能停止的所有位置都成立。先写临时路径，再重命名到最终位置。

检查：连续执行两次会怎样？上次在每个可能的位置崩溃又会怎样？如果答案取决于留下了什么状态，就增加协调恢复步骤。
