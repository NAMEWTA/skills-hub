# 01 Home 派遣初始化、任务与占用验收

隔离 Home 通过已安装技能创建了原生默认和最小 team，并使用实际原生子 Agent 完成已登记项目的只读任务。项目负责人报告实际 checkout、当地 `AGENTS.md`、HEAD 和本地证据，Home 独立比对后归档回执、验收并释放项目。两份 TSV 均记录结案，重装技能后的查询仍返回相同结论。

相同隔离 Home 中独立保存第二种派遣方式及 team，验证关联指针与原默认共存。另一份旧 Home fixture 经安装后保持原偏好、团队和登记字节。显式补初始化复用了旧 team，分出原生派遣默认，保留无关偏好和登记。替代宿主及不兼容组合经过规则走查，未运行相应外部工具。

- `npm run check:full` 退出 0，503 项测试中 499 项通过、4 项跳过，覆盖多项目同批投递的记录、竞争占用、状态恢复、旧资料保护和视图重建。
- `npm run check:package` 退出 0，实际打包并安装 64 个技能，1099 个分发文件。安装验证覆盖新技能闭包、同仓链接和重装行为。
