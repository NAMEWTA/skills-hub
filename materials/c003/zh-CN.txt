# AGENTS.md — 已归档 Agent Notes

类型目录下已归档的 Agent Note 三文件组是冻结历史快照，不是当前权威依据。不编辑、重排格式、翻译、修复、删除或移动已封存产物；新决策与事实使用活动 Agent Note 或当前文档。

归档变更只允许搬迁完整的英文、中文、附属记录三文件组，在两个 `Status: implemented` 下方插入相同的 `Archived: YYYY-MM-DD` 行，重新记录附属文件，以及修复或删除入站链接。不检查、验证或修复归档笔记的出站链接。

执行 [`dsh-archive-agent-notes`](../../skills/dsh-archive-agent-notes/SKILL.md) 工作流，并用 `pnpm run verify-archived-agent-notes --write` 追加新产物哈希。普通校验器拒绝被修改或缺失的已封存产物、不完整三文件组、未知类型目录，以及无效归档元数据。

从 `feature/2026-08-10-durable-workflow-runs-in-chat` 移除 Figma 链接的已授权修改，在 `scripts/archived-agent-notes.ts` 中为英文、中文和配对文件各设置一个精确的旧封存值到新封存值例外，共三个。这些例外不允许任何其他内容修改、反向变更或删除。
