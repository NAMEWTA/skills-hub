# 安装契约

## 源码和安装结构

源码由 `skills/<domain>/<domain>-xxx/SKILL.md` 自动发现，不另建人工维护的技能注册表。安装后完整复制到当前工作目录的 `.agents/skills/<domain>-xxx/`，保留 references、assets、scripts 和 agents 等全部运行资源。完整许可从仓库 `licenses/` 自动附带到 `.agents/skills-wta-licenses/`，不放进技能目录。只安装一个技能也附带完整许可，使用者不需要选择或维护许可组合。

安装器无网络访问、无第三方运行依赖，不安装包管理器、不修改 Agent 的全局配置，也不决定使用者的项目根目录。请先切换到目标项目根目录再运行；它有意不提供 `--target` 或安装目录交互。在本仓库的 `skills/` 或 `licenses/` 源目录及其子目录中运行安装会被拒绝，避免把技能复制进自身。

## 选择

| 命令 | 行为 |
| --- | --- |
| `list` | 列出当前源码中的全部领域和技能 |
| `list --domain dev` | 只列出该领域 |
| `install --domain dev system` | 安装所列领域的全部技能 |
| `install --skill dev-spec system-proxy` | 安装所列技能，允许跨领域 |
| `install --domain system --skill dev-learn` | 领域选择与技能选择取并集，去重 |
| `install --all` | 安装全部领域 |
| `install … --dry-run` | 检查选择和冲突，展示计划，不创建目录或文件 |
| `install … --replace` | 对不同内容先备份再替换 |

没有选择、未知名称或非法源码命名会返回非零退出码。不能把拼错的技能静默跳过。

## 更新与冲突

第一次安装直接复制。相同文件内容再次安装返回 `unchanged`，不修改技能。已有同名目录或配套许可目录但内容不同，默认整次安装停止；在任何技能变更前先完成冲突检查。许可缺失会在下次安装时补齐，即使选定技能内容没有改变。

更新源码后，先查看改动，再运行 `--replace`。旧目录保留在 `.agents/.skills-wta-backups/<UTC时间-随机后缀>/<技能名>/`。备份在技能扫描目录之外，不会作为重复技能加载。未选中的技能不改动。配套许可的旧副本保存在同批备份的 `.licenses/` 中；许可与所选技能一起暂存、切换并在失败时恢复。

安装先把所有新文件复制到同文件系统的临时目录，再逐个切换。普通复制或切换异常会尝试撤销本次已切换目录；撤销失败时明确报告需要人工恢复的位置。它不承诺断电、强制终止或外部程序同时修改下的完整事务。

`.agents/.skills-wta-install.lock/` 防止本安装器并发写入。若异常终止留下锁，先确认没有安装进程，再移除锁并检查备份。不要在进程运行时删除锁。

## 恢复与卸载

恢复前关闭可能正在读取或写入这些技能的工具，核对备份内容，将现有对应技能另行保留，再把选定备份目录移回 `.agents/skills/<技能名>/`。只恢复所选技能，不用整个 `.agents` 覆盖项目资料。

不再使用某技能时，移走其 `.agents/skills/<技能名>/` 文件夹即可。安装器不提供一键递归清空功能。它从不删除 `.agents/notes/`、需求记录或部署资料。仍保留任何本项目技能时，保留 `.agents/skills-wta-licenses/`；转移或再次分发技能时同时附带该目录。卸载全部技能后才可移走这份配套许可。

## 平台与工具

Python 3.10+ 标准库。Windows 使用 `py -3` 或实际 Python 命令；路径含空格时按当前 shell 规则加引号。源码和安装目标中的符号链接、设备、管道会被拒绝，避免复制到技能范围之外。相等判断比较文件路径与内容，在 POSIX 平台还检查执行位以支持脚本权限更新；不把空目录作为状态，也不比较其余平台权限。

安装器不执行任何技能中的脚本，不自动连接 Figma、服务器或外部账号，不安装兄弟技能的隐含依赖。支持 `.agents/skills/` 的 Agent 可按其发现规则读取；其他 Agent 由用户显式加载文件。技能可调用性仍受宿主实际工具能力限制。
