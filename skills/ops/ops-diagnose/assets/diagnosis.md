# 运行诊断

- run / 步骤 / 采集窗口与时区：
- 稳定目标、项目环境和真实入口：
- 最新已完成检查时间：

## 发生了什么

一句话写清症状、开始时间与当前表现。

## 根因判断与置信度

写机制、支持/反对证据及高/中/低置信度。未知时保留为候选，不用猜测填满。

## 影响范围

区分直接失败、已证实共享影响、可能影响和未覆盖对象。

## 建议处理

写具体动作、为何适用、已有授权、实际效果边界及处理后观察。需要发布/迁移时形成项目交接。

## 已排除

列已检查的替代解释及真实排除证据；不完整查询不能提供“未发生”的证明。

## 会改变判断的观察

写最有区分力的下一项证据，以及如何取得。

## 实际处理与复验

只填写确实发生的操作和验证，链接对应步骤；区分临时缓解、服务恢复、原因确认及仍未知事项。
