# 01 Home Git 与换机验收

在 Windows、Node.js 24.21.0、Git 2.47.1.windows.2 上完成验证。

- `npm run check:full` 退出 0。508 项中 504 项通过，4 项按运行前提跳过。新增用例验证忽略规则保留、独立 Git 和 worktree、已存在索引冲突、初始化部分失败后的接续等情况。
- 通过实际安装器制作隔离 Home，然后提交并克隆到另一个目录。新位置没有技能缓存、本机映射、`.claude` 或旧运行原件。使用仓内技能取得事件的决定理由、现行知识的验收条件，以及任务要求和回执的下一步。拿不到旧日志时，所需信息仍可从正文读取。
- 新克隆从 Git 测试远端恢复了内嵌项目和平级项目，分别核对默认分支、主远端名称、多个 fetch URL、显式 push URL 和附加远端。v1 登记原字节保持一致。不可达远端、占用路径和本机独有项目逐项报告，另两个项目仍成功。跨身份 URL 重写在克隆前被拒绝。重跑时保留已有 checkout 的脏文件和暂存区。
- `npm run check:package` 退出 0。实际打包安装 64 个技能和 1103 个分发文件，覆盖命令入口、包内资源、同仓链接和重复安装。`git diff --check` 通过。

在实际 Home `D:/Document/code` 使用安装后的技能建立本地 `main`。9 个 Home 技能齐备，400 个文件可跟踪，索引为空。9 个独立项目目录均被忽略，前后比对项目 HEAD、分支、索引和工作区状态一致。恢复预览核验了 8 个已登记项目的身份并报告原地复用。已知的本机路径和运维凭据文件均被忽略。

当前实际 Home 只有本地初始化状态。首提交、远端和同步由用户决定。隔离换机验收使用本地 Git 测试远端，未连接实际私有远端，未验证另一台物理机器的访问权限。
