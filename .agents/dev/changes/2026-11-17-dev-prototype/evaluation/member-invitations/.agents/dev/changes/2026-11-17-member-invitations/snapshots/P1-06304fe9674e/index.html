走查提示
  1. 点击“邀请成员”，用新邮箱选择成员或只读角色；提交后观察等待、成功与列表新增。
  2. 试试空邮箱、错误格式、已有成员 lin@example.test，或重复邀请列表中的邮箱。
  3. 把发送结果切为“下次失败，重试成功”，提交后保留输入并重试。
  4. 点击邀请的“查看”，先取消一次撤销，再确认撤销；观察列表与数量变化。
  5. 切换普通成员查看权限说明；用“演示空态”“演示长邮箱”检查不同数据状态。
  6. 在窄屏打开抽屉；试用 Tab、Shift+Tab、Enter 和 Escape。发送中关闭抽屉会取消本次模拟请求。
