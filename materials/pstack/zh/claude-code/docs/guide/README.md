# pstack 指南

不再微观管理代理时，pstack 最有效。描述你要什么，以及如何判断完成；`/poteto-mode` 选择操作流程，在步骤需要时运行其他技能，再展示证据。本指南用真实提示词培养这种习惯。

你将学到：

1. [配置 pstack](./01-setup.md)：安装插件并选择模型。
2. [通过 `/poteto-mode` 分派工作](./02-poteto-mode.md)：给它目标，看它选择流程。
3. [理解代码](./03-understand.md)：先只读调查，再在修改前用 `/how`、`/why`、`/teach` 和 `/recall`。
4. [设计变更](./04-design.md)：在代码固定形状前使用 `/architect`、`/arena`、`/swarm`、`/interrogate`、原型和计划。
5. [构建并清理变更](./05-build-and-clean.md)：构建流程、`/tdd`、`/unslop` 和 `/no-comments`。
6. [验证并交付](./06-verify-and-ship.md)：在真实应用中证明行为，形式化验证测试难触达的情况，用 `/benchmark-checklist` 核验数字，再开一个聚焦的 PR 并推进到合并。
7. [睡觉时继续工作](./07-overnight.md)：先信任再循环，夜间约定，可审计决定日志，以及超出单代理规模的 Projects 与自动化。
8. [用原则名称引导](./08-principles.md)：24 个能在任务中途重新引导代理的名称。
9. [变成自己的工作方式](./09-make-it-yours.md)：自己的模式，用 `/correct` 解决重复错误，以及如何测试技能变化。
10. [常用做法与常见问题](./10-recipes-and-pitfalls.md)：可复制提示词和应避免的错误。

第一次按顺序阅读，之后每页都可以独立使用。

卡住或不确定哪个技能适合时，输入 [`/poteto-help`](../../skills/poteto-help/SKILL.md) 和问题：

```text
/poteto-help 我应该用哪个技能审查这个分支？
```

它回答问题，给出一条可发送提示词，并链接到答案对应的技能或指南页。它不开始工作，因为一次 pstack 执行会消耗真实 token，所以你准备好后再发送提示词。只有显式输入时它才运行。

## 只记住一件事的话

用自己的话给代理目标与检查方式：

```text
/poteto-mode 运行中途发生重试时，导出会写入重复行。先复现，再修复并验证。
```

不需要指定流程或列出技能。“先复现”和可检查结果，已经给出 `/poteto-mode` 所需的全部分派信号。它匹配缺陷修复流程，把步骤复制到任务清单，并在每一步调用适合的技能。
