# 决策访谈、行为规格与实施计划

用户在渠道门户 Change 中发现，已有 `brief.md` 成为了行为规格，文件中只剩 Q1–Q9 的结论摘要。此次调整让三个技能各自交付可找到、可续作的 Markdown 记录。

## 行为与验收

| 入口 | 预期行为与通过条件 |
| --- | --- |
| 决策访谈 | 独立访谈保存 `decisions.md`。记录待答问题和依赖，收到答复后追加选择、理由与来源；更正指向被取代的记录。地图调用写回问题文件，地图保留摘要和链接。 |
| 正式规格 | 同一 Change 的 `spec.md` 保存当前行为、边界和验收；已有规格原处修订。旧 brief 的现行行为迁入规格，保留 brief 的背景、原始来源和可核实历史。存量引用指向实际内容。 |
| 正式规划 | 先具备 `spec.md`，再保存 `plan.md`、逐张票据及同名初始证据报告；单票也能完整交接。探路只保存地图和问题，阻塞及写入中断后从实存文件接续。 |
| 分发与验证 | 同步运行入口、支持材料和调用方。以隔离项目检验访谈、旧规格迁移、计划和恢复，并运行仓库检查。 |

维护范围为本仓库。cde-token 的渠道门户仅作为隔离验证输入。逐项采用和适配见[上游对照](source-adaptations.md)。
