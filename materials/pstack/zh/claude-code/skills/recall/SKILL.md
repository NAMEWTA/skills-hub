# 回忆工作上下文

在 Claude Code 中，每个会话在遵循此技能前，先阅读一次 [Claude Code 适配器](../../docs/harness/claude-code.md)。它将 pstack 技能中的 Cursor 名称映射到 Claude Code。

**开始或恢复工作之前，重建用户最近的工作上下文，返回紧凑的现状概括和下一步。**

保持紧凑、切题。只读取范围内工作线索所需要的内容，然后停止。

你的上下文存在于两份记录中。自己的聊天历史保存你做过什么、作过什么决定。共享记录保存围绕同一份代码、以其他名称出现的所有事情：用户反复报告的症状、曾经发布又被回退的修复，以及生产环境中仍在触发的错误。第二份记录位于源代码管理、问题跟踪器、聊天和问题频道、长篇文档以及错误追踪系统。一个有长期缺陷尾巴的功能，其大部分经历都在那里，因此不要只根据自己的会话记录重建它。

会话记录位于 `~/.cursor/projects/<slug>/agent-transcripts/<uuid>/<uuid>.jsonl`。`<slug>` 是删除开头斜杠、再把每一个 `/` 替换成 `-` 后的工作区路径，例如 `/Users/you/proj` 变成 `Users-you-proj`。每行是一条聊天消息。

1. 先分类，再路由。恢复某一条具体旧会话应使用 `session-pickup` 操作手册，不是本流程。把习惯变成持久技能应使用 `automate-me`。供人阅读的工作总结又是另一项任务。回忆是在行动前，跨最近会话加载工作上下文。如果用户已给出完整状态胶囊，包括路径、分支和改动，就使用它并跳过挖掘。
2. 搜索前固定范围。明确时间窗口：“最近”必须是真实区间，默认最近 7 天；明确用户指出的主题，以及工作区，默认当前活动工作区。未被要求时，绝不读取另一个项目的会话记录。复述搜索范围。绝不悄悄把“全部”改成“最近 N 条”。
3. 在聊天历史中分散搜索。用快速、低成本的模型启动并行子代理，每个负责语料的一部分。要求每个子代理按真实修改时间（`ls -t`）排序候选记录，绝不按 UUID 名称排序；先 grep 主题，然后只读匹配的聊天及其中相关区域，并跳过当前聊天和明显噪声（子代理、评估和测试聊天）。每个子代理按相同结构返回，每段对应一次聊天：主题、用户目标、决定、未完事项、困难与纠正，以及产物（PR、工单、分支），每项均引用聊天 UUID。只有一两个聊天时，跳过并行分散，直接搜索。原始会话记录留在子代理中，主线程只接收其发现。按照 **poteto-mode** 技能的 Subagents 部分，为每个子代理选择适合任务的推理级别。
4. 只要主题点名某个功能、文件、子系统、领域或缺陷，就扫描共享记录。这是默认步骤，不由临场判断决定，“我在 X 上的工作”也不例外。每个来源启动一名调查子代理，使用 agent 模式，因为 readonly 会移除 MCP 访问权限，并分别询问“当前状态是什么、尝试过哪些未能持续奏效的措施、用户仍在报告什么”。它们与聊天历史挖掘并行运行。没有结果也是发现。跳过不可用的 MCP，并说明情况。将返回内容汇入简报。只有纯活动回顾且没有指明目标时（“这周我做了什么”）才跳过此步骤，此时自己的历史和实时状态足以构成完整答案。
5. 对照实时状态验证。取得挖掘和共享记录检索找到的 PR、分支、工单，用 `git` 和 `gh` 核对。如果答案取决于代理实际做了什么，例如运行了什么工具、读了什么文件、遇到什么错误，就读取完整会话，而不只读裁剪过的本地副本。
6. 按下面的输出契约撰写简报。按工作线索分组，始终围绕指定主题。

## 输出契约

先给状态胶囊，再给各条工作线索的状态，然后列问题，最后给下一步。更深细节放后面或删去。

- **状态胶囊。** 最多 5 个要点。说明这项工作是什么、整体到哪里了。
- **工作线索。** 每条一行，前面恰好放一个状态标签：`[merged #N]`、`[open PR #N]`、`[in flight <branch>]`、`[verified, uncommitted]`、`[reverted #N]` 或 `[planned, not started]`。没有标签的工作线索还没有处理完，因此给它加标签。
- **问题。** 最多 5 项，选择反复出现的。包括用户反复报告的症状，以及已上线又回退的修复，让下一次尝试从上一次失败的位置开始。
- **下一步。** 一项最有用、具体的后续动作。

相邻功能或工单除非阻塞当前目标，否则不纳入。当状态胶囊和工作线索超过一屏时，先删细节，不先删工作线索。通过 **unslop** 技能撰写简报；聊天发现用 UUID 引用，共享记录发现引用其来源，例如 PR 编号、工单 ID、聊天永久链接、错误跟踪问题；公开输出前脱敏私人上下文。

**回复：** 按上述契约给出简报。
