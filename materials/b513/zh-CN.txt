# benny

benny 为 Slack 问题报告提供两个 Cursor 自动化。一个分诊每份报告，另一个复现已确认缺陷，并可能准备一份小型草稿修复。

本目录中的文件是尚未启用的安装与自动化来源材料。它们不会作为斜杠技能出现。

## 安装

1. 让 Cursor 读取 [FOR_AGENTS.md](./FOR_AGENTS.md)，并指定目标仓库。
2. 让安装流程把整个目录合并到目标的 `.cursor/automations/benny/`。它必须保留仅存在于目标中的文件，审阅冲突，而不是覆盖本地编辑。
3. 让安装流程在目标仓库的 `.cursor/settings.json` 中启用 pstack，以提供共同依赖：

```json
{
	"plugins": {
		"pstack": { "enabled": true }
	}
}
```

4. 用户拥有的配置保存在复制包之外，例如 `.cursor/benny/`。适配 [configuration.example.yaml](./templates/configuration.example.yaml) 和 [feature-map.example.md](./skills/reproduce-and-fix-issues/references/feature-map.example.md)。
5. 启用任一自动化前，提交 `.cursor/settings.json`、`.cursor/automations/benny/` 及所有不含秘密的配置。
6. 审阅每个新自动化草稿，或在编辑器中更新已有自动化。然后发送一份无害测试报告，验证来源频道中的每条消息都留在原始讨论串内。
