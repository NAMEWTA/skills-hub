# 学习记录格式

学习记录位于 `./learning-records/`，顺序编号：`0001-slug.md`、`0002-slug.md` 等。按需创建目录：只在写入第一条记录时创建。

它们是教学中的 ADR：记录不显而易见的经验、关键洞见，以及会引导未来会话的已陈述先前知识。用于计算最近发展区。

## 模板

```md
# {所学或已确认内容的简短标题}

{1–3 句话：学到了什么（或确认了哪些先前知识），以及为什么它对未来会话重要。}
```

这就是全部格式。一条学习记录可以只有一段。价值在于记录_这件事_现在已知，以及_为什么_它会改变下一步教学，而不在于填满各节。

## 可选部分

仅在确实增加价值时加入。大多数记录不需要。

- **Status** frontmatter（`active | superseded by LR-NNNN`）：早期理解被证明错误、被替换时有用。
- **证据**：用户如何展示理解（回答问题、完成练习、引用先前经历）。未来可能重审该主张时有用。
- **影响**：为未来会话解锁或排除什么。不显而易见时值得记录。

## 编号

扫描 `./learning-records/`，找到已有最大编号并加一。

## 何时写学习记录

以下任一成立时写：

1. **用户展示了对非平凡内容的真实理解**：不仅接触过，而是有证据表明能正确使用概念。这为下一步教学建立新起点。
2. **用户披露先前知识**：“我已经知道 X。”记录下来，避免未来重新教授。还要记录其声称的_深度_。
3. **误解得到纠正**：用户以前相信错误内容，现在明白为什么错。此类记录价值很高，能预示相关主题未来的绊脚石。
4. **学习促使使命改变**：用户发现自己真正关心的不同于原先想法。交叉链接 [[MISSION.md]] 并更新它。

### 什么_不_符合

- 仅仅讲过的内容。覆盖不等于学习，等待证据。
- 已经作为术语定义简洁记录在 [[GLOSSARY.md]] 的内容。不要重复。
- 逐次会话活动日志。学习记录不是日记，而是足以支持决策的洞见。

## 取代关系

后续记录与早期记录矛盾时（用户理解加深或纠正），将旧记录标记为 `Status: superseded by LR-NNNN`，而不是删除。理解如何演变的历史本身就是有用信号。
