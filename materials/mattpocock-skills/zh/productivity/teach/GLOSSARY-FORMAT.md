# GLOSSARY.md 格式

`GLOSSARY.md` 是本教学工作区的规范语言。所有讲解、练习和学习记录都应遵循其术语。构建术语表本身就是学习的一部分：把概念压缩成紧凑定义，是用户理解它的证据。

## 结构

```md
# {主题}术语表

{用一两句话描述本术语表涵盖的主题。}

## 术语

**肌肥大（Hypertrophy）**：
在反复训练中，由机械张力和代谢压力驱动的肌肉生长。
_避免_：增重、变大块

**渐进超负荷（Progressive overload）**：
通过负重、训练量或强度，随时间有系统地增加肌肉承受的要求。
_避免_：更拼命、升级

**RPE（自觉用力程度）**：
以 1–10 自评一组训练有多费力，10 表示力竭，8 表示还能做两次。
_避免_：努力分数、强度评分
```

## 规则

- **只有用户理解术语时才添加。** 术语表记录压缩后的知识，不是供用户阅读学习的词典。刚介绍概念时，先等用户能正确使用，再提升到这里。
- **立场明确。** 同一概念有多个词时，挑最好的一个，其余列为应避免的别名。这就是语言压缩的方式。
- **保持定义紧凑。** 一两句话。定义术语是什么，不是它做什么或怎么做。
- **定义中使用术语表自己的术语。** 某术语加入后，所有地方都优先使用，包括其他定义内部。这使后续复杂术语更易掌握。
- 出现自然聚类时，**按子标题分组**（例如 `## 解剖学`、`## 训练计划编排`）。术语彼此紧密关联时，扁平列表也可以。
- **明确标注歧义。** 某词在更大领域使用宽泛时，注明本处解释：“在本工作区，‘组’始终表示正式训练组；热身另行记录。”
- **随理解加深而修订。** 用户第一周写的定义，到第六周可能是错的。原位更新，不留过时条目。
