# 01 三项技能验收

已核对 [票据](../tasks/01-skill-contracts.md) 涉及的三项技能入口、完整方法、模板和 UI 元数据。工作产物有固定位置，各入口给出可回读的完成条件。

- 隔离访谈保存首轮问题，收到选择与理由后生成依赖问题。改答保留旧条目。地图问题收到答复后保存到原问题并更新索引。
- 门户变更副本从旧 brief 生成正式规格，行为条款与八项验收完整传递。当前 Change 内 20 个规格引用已通过路径和锚点检查。
- 单票和三票计划分别保存规格、计划及配对报告。恢复用例补齐缺失索引及报告，原规格、原票号与票据内容保持一致。

实际执行和宿主限制见[隔离验收](03-validation.md)。
