# 团队成员邀请

已明确的产品目标：管理员可以在现有成员页邀请新成员并撤销尚未接受的邀请。继承 current/index.html 的导航、深色配色、密度、圆角和强调色。邀请采用右侧详情抽屉，保留列表上下文。

## 行为

1. 成员页提供邀请入口；在抽屉内填写邮箱，选择“成员”或“只读”角色。
2. 邮箱必填且格式有效；重复邀请已有成员或尚未接受邀请的邮箱时提示原因并保留输入；可取消，返回列表且不产生邀请。
3. 提交显示等待。成功后待接受邀请出现在同页邀请列表，显示邮箱、角色与待接受状态；关闭抽屉后列表保留新邀请。
4. 发送失败保留表单内容，显示明确原因与可用重试；重试成功后结果与首次成功一致。
5. 可以打开一条待接受邀请查看详情，执行撤销时先确认；取消撤销仍保留邀请，确认撤销后从待接受列表移除并有结果反馈。
6. 没有邀请时给出空态及可用邀请入口；仅普通成员查看时可以看成员与邀请，但没有创建/撤销权限，界面说明其不可用原因。
7. 目标视口包括桌面和窄屏；抽屉支持 Escape 关闭与焦点返回，不遮住必要操作。提供模拟成功、失败、权限切换及重置，使用虚构数据，不发真实邮件。

## 边界

邀请接受页面和真实邮件服务不在本次原型范围；生产实现仍需服务端授权、邮箱规范化与原子去重。原型里模拟成功不证明这些能力完成。

用户将亲自打开可交互 HTML 后确认最终效果；当前仅认可上述文字需求，尚未认可原型。
