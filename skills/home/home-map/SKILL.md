# 项目关系与影响范围

交付有来源、方向、契约 owner、版本和核查时间的关系，以及本次变化的影响范围。当前关系结构由 `.agents/home/relations.md` 维护；已有等价权威文档原地使用，不复制另一份可编辑图。

## 执行

先读[关系核实与影响分析](references/relations.md)，以[关系模板](assets/relations.md)组织实际记录。

1. 从实际 Home 根读取 `./.agents/home/AGENTS.md`，明确当前问题、变化和相关 repo ID，读取已有关系与必要 Home 背景。名称相近、同组、同一 owner 或同一派遣图不构成依赖证据。
2. 通过 `home-route` 取得本次实际 checkout。需要当前技术事实时，向 `home-workflow` 交付准确的项目调查目标，由用户选择的当地方法把任务交给项目 Agent。
3. 由各项目在当地核对源码、配置、发布物或权威文档，返回简短结论、原件路径、相关 revision/时间和边界。Home 不打开项目内部正文代为调查。
4. 区分生产者/消费者、关系类型、信息方向、契约 owner 与状态；核对双方描述。矛盾未消解时标争议或候选，不用旧图推定当前行为。
5. 根据本次变化沿相关关系形成直接和间接影响集合。缺证据的边说明不确定性，纯参考关系不自动升级为运行阻塞。
6. 原地更新关系 owner 并修复必要引用；长期理由交 `home-knowledge`，有价值的变更事件交 `home-history`。将需要联合验证的组合和缺口交 `home-integrate`。

## 完成条件

能回答“谁提供、谁消费、哪类关系、契约谁维护、何时/哪个版本核实、改动影响谁、还不知道什么”。图或表只作为导航与证据摘要；项目接口全文、设计知识、测试原件留项目。不得据关系图扩大权限、自动发布或越级控制项目子 Agent。
