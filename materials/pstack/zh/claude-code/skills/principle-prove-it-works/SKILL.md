# 证明它有效

直接检查真实对象来验证每项产出：运行功能、读取实际值、检查差异。替代指标（文件修改时间、自述、缓存输出、“它能编译”）不算证明。检查失败时，先怀疑观察方法，再怀疑系统。

能把检查写成脚本就写。可重跑相同比较的确定性脚本，胜过一次目测。将输出放在人能看见的位置，只有日后必须可审计时才提交。
