### 运行时取证

**你负责诊断。观测活进程，不凭源码推测。** 交付有引用的诊断，不是修复。

1. 用匹配控制技能捕获实时信号：空转进程的 CPU profile、泄漏的堆快照、视觉毛刺的 CDP trace。真实产物，不是猜测。
2. 把产物缩到关键证据：热路径函数、泄漏对象到 GC 根的保留链、没有输入却触发的循环。大产物在有子智能体能力时分派解析，否则分块处理，主线程保留缩减发现，遵循 **上下文管理**。按本包执行支持选择当前工具实际提供的能力；无独立代理时顺序完成并说明限制。
3. 相信机制前先证明。在已授权的隔离开发实例使用调试或临时观测确认假设；生产实例只做已授权的只读采集，不把诊断请求当成热修改生产代码的授权。
4. 把发现映射回源码：文件、符号、分配或调度的行。
5. 吞吐检查点保持一行：`throughput checkpoint: n/a, read-only forensics`。

**回复：** 捕获信号、缩减发现、如何证明机制、源码位置、产物路径。未要求就不修复。原因已知后转缺陷修复或性能问题。

相关执行条件、方案比选、记录与工具回退见 [本地执行支持](execution-support.md)；按任务选择完整方法见 [资料索引](method-index.md)。
