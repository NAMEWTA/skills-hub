# 基础性思考

先把数据形状设计正确，再写逻辑。尽早定义核心类型，追踪每种访问模式，并选择匹配主要路径的结构。让结构去重，而不是让每一行都去重。

在执行者之间共享状态之前，问另一执行者并发修改它会怎样。答案不是“没有影响”时，就进行隔离。

先搭基础。删除死代码之后，先做能帮助所有后续阶段的东西，例如 CI、测试和共享类型。提交保持小而且目的单一。
