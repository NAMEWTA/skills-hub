# 随包提供的查看器语言目录

`manifest.json` 登记由 `meta.locale` 自动选择的语言目录。渲染器只会读取其中列出的文件，并以当前已安装目录为相对路径基准。它绝不会扫描该目录、工作目录或其他位置来寻找语言文件。

`en.json` 是规范消息集合，也是最终回退来源。其他每个语言目录都会逐键与其校验：缺失的条目、未知条目或占位符不匹配的条目，会回退到英文，并在渲染该语言时报告。因此，新增 UI 键可以先以英文发布。

每条消息按以下优先级解析：有效的 `meta.translations` 值 → 所选随包语言目录 → 英文。参见[创作契约](../references/authoring-contract.md)。

要登记一种语言，在此处添加其完整语言目录，并增加一条清单记录即可，不需要修改渲染器或 schema。语言标签匹配不区分大小写；地区和文字变体（例如 `zh-Hant`）是独立标签，绝不会合并到其他语言目录。

完整性检查只能证明键与占位符的覆盖情况，不能证明母语措辞、复数语法、从右到左的布局或字形覆盖情况。

阿拉伯语目录只本地化文案。阅读器文本与界面的方向、场景几何均保持不变；完整 RTL 支持由 [#935](https://github.com/tt-a1i/archify/issues/935) 跟踪。路径／可达范围的导出摘要与可达范围控件，在现有 `.one`／`.other` 模型下使用不区分数量的标签。其他包含计数的消息仍受该模型在阿拉伯语复数表达上的限制。

其他可复用但尚未登记的示例位于 `../examples/locales/`；通过 `meta.translations` 提供它们。
