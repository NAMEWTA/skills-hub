# 分诊标签

这些技能使用五个规范分诊角色。本文件将这些角色映射到本仓库问题跟踪器实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们跟踪器中的标签 | 含义 |
| ------------------------ | ------------------ | ---- |
| `needs-triage` | `needs-triage` | 维护者需要评估此问题 |
| `needs-info` | `needs-info` | 等待报告者提供更多信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已完整，可交给无人值守（AFK）代理 |
| `ready-for-human` | `ready-for-human` | 需要人类实现 |
| `wontfix` | `wontfix` | 不会处理 |

技能提及某个角色时（例如“添加 AFK-ready 分诊标签”），使用此表中对应的标签字符串。

编辑“我们跟踪器中的标签”列，使其匹配你实际使用的术语。
