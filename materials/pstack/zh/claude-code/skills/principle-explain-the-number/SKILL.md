# 解释数字

- **运行前写下要作出的决定。** 说明什么结果会改变该决定，以及噪声下限。多次运行之间的波动大于效果时，停止。
- **问“为什么不能好一倍？”** 根据运行时取得的剖析结果或计数器，指出限制结果的资源或代码路径。读代码猜出的原因不算限制因素。
- **列出数字还可能在衡量什么**（错误、跳过或缓存的工作、根本没运行的代码、未调优的一方、噪声、对整体小到无关紧要的局部），并用证据逐一排除。
- **把运行次数、波动范围和限制因素与数字一起保存。**

性能数字使用 [benchmark-checklist](../benchmark-checklist/SKILL.md) 技能。评估结果则检查每次运行是否都完成了任务、差距是否在不同试验及模型间成立，以及场景是否重要。
