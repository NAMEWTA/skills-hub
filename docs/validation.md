## 行为前向验证

使用仅安装目标技能的独立项目，由未参与编写该技能的新代理执行真实任务：

**dev-debug：CLI 超时时间显示错误。** 代理读取规格、复现同一 CLI 路径，发现毫秒换算错误及通用浮点格式造成的精度丢失，随后修改实现并补回归检查。实际 CLI 输出覆盖默认值、小数毫秒和大整数场景，原重试调度保持不变。验证顺序为规格/观察、实现、实现后回归。

**dev-archive：移除 WebSocket，但离线导出与持久化格式保留，同时移动源码文件。** 代理核对源码并执行轻量回放检查，更新现役背景与代码路径，保留仍有效的事件日志 ADR 和原始取舍，归档完成的需求并修复相关链接。没有凭一次传输删除就退役整个持久化决定，也没有因文件改名建立虚假的新决定；未获取历史数据样本的限制明确写入记录。

这两次结果证明这些具体情景下的可用性，不代表所有语言、项目或部署方式都已验证。
