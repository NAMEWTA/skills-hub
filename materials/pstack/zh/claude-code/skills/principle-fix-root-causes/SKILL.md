# 修复根因

修复错误本身，而不是它显现的位置。根因是系统首次做了不该做的事，或没有处理本应处理的状态的位置。

- 先复现。不断追问“为什么”，直到答案是代码中的错误决策。受阻时加入观测，读取实际状态。
- 判断触发症状的状态是否合法。合法就应在代码出错处处理它。如果该状态本不该存在，在那里添加检查会隐藏缺陷，应找出是什么产生了它。守卫、重试、吞掉错误、钳制数值及丢弃状态，都是常见的隐藏缺陷方式。
- 修复整个模式，而不只是单个实例。找出所有有相同错误的位置。
- 如果决定性事实需要深入挖掘才能找到，提出一种成本低、始终开启的信号，让人第一眼就能看见它。
